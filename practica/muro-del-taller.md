# Muro del taller

Este archivo es para la parte opcional colaborativa de la práctica.

## Instrucción

Si el facilitador lo indica, agrega una sola línea con este formato:

```text
- Nombre | Materia | Qué esperas aprender en el taller
```

## Ejemplo

- Tu Nombre | Tu materia | Quiero entender cómo usar GitHub para recibir tareas con más orden
