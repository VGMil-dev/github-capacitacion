## ¿Qué vas a lograr?

Al terminar este roadmap deberías poder:

- entender qué es **Git** sin sentirlo como algo intimidante;
- distinguir qué hace **Git** y qué hace **GitHub**;
- seguir un flujo simple de trabajo con cambios, commits y entregas;
- usar GitHub para recibir tareas y revisarlas con más orden.

:::note[Lo más importante]
No necesitas experiencia previa. Este recorrido está pensado para docentes que **nunca han tocado Git en su vida**.
:::

## Antes de empezar

- [ ] Tener una cuenta de GitHub o estar listo para crearla.
- [ ] Tener acceso a un navegador y, si es posible, VS Code o una terminal.
- [ ] Llegar con la idea de aprender un flujo simple, no Git avanzado.

## Cómo te recomiendo recorrerlo

1. Empieza por **Etapa 1** aunque nunca hayas usado Git.
2. Pasa a **Etapa 2** para familiarizarte con el lenguaje básico.
3. En **Etapa 3** entiende GitHub sin presión.
4. Usa **Etapa 4** para hacer una práctica real y sencilla.
5. Recién después pasa al flujo completo del estudiante y del profesor.
6. Deja lo avanzado para el final, cuando ya te sientas cómodo.

:::tip[Meta final]
La meta no es volverte experto en Git. La meta es que puedas usar una herramienta real para **ordenar entregas, revisar mejor y enseñar con más claridad**.
:::
