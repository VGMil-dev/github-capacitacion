# Etapa 3: Conociendo GitHub

Ya sabes que Git guarda la historia de un proyecto. Ahora toca entender dónde entra **GitHub**.

## Git y GitHub no son lo mismo

### Git

Vive principalmente en tu computadora y te ayuda a registrar cambios.

### GitHub

Es la plataforma en la nube donde puedes publicar repositorios, compartirlos y colaborar con otras personas.

## Una forma fácil de verlo

- **Git** te ayuda a ordenar tu trabajo.
- **GitHub** te ayuda a compartirlo y revisarlo con otros.

## ¿Por qué GitHub sirve en el aula?

Porque permite:

- publicar una tarea base;
- recibir entregas sin mezclar archivos raros;
- revisar exactamente qué cambió cada estudiante;
- dejar retroalimentación dentro del mismo trabajo.

## Qué vive en tu computadora y qué vive en la nube

| Lugar | Qué pasa ahí |
| --- | --- |
| Tu computadora | Editas archivos, revisas cambios y haces commits |
| GitHub | Publicas el repositorio, compartes el trabajo y abres revisiones |

## Palabras nuevas que ahora sí importan

### Push

Es subir tus cambios locales a GitHub.

### Clone

Es traer una copia del repositorio a tu computadora.

### Pull Request

Es una forma ordenada de proponer o entregar cambios para que otra persona los revise.

## Qué viene después

Ahora sí estás listo para hacer una práctica sencilla antes de ver el flujo completo:

1. hacer un fork;
2. clonar tu copia;
3. editar un archivo simple;
4. hacer commit y push;
5. abrir tu primer Pull Request.
