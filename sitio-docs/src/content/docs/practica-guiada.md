# Etapa 4: Práctica guiada

Esta es la práctica fija del curso. Su objetivo es que cada docente haga una entrega real sin que el ejercicio se vuelva complicado.

## Repositorio que usarás

Para esta práctica **no necesitas crear un repositorio nuevo**.

Usaremos este mismo repositorio, **Capacitacion**, como repositorio base del profesor. Durante el ejercicio, cada docente asumirá el **rol de estudiante**:

1. hace **Fork** de `Capacitacion`;
2. trabaja sobre su propio fork;
3. abre un Pull Request de regreso hacia este repositorio.

## Objetivo de la práctica

Afianzar en un solo ejercicio estos pasos:

1. hacer **Fork**;
2. clonar el repositorio;
3. editar un archivo simple;
4. hacer `git add`, `git commit` y `git push`;
5. abrir un Pull Request.

## Qué vas a usar

Dentro de este repositorio encontrarás la carpeta:

```text
practica/
├── README.md
├── participantes/
│   └── plantilla-perfil.md
└── muro-del-taller.md
```

También verás una carpeta llamada `sitio-docs/`, pero esa pertenece al sitio de documentación. Para la práctica, puedes ignorarla por completo.

## Parte obligatoria: tu archivo personal

Cada docente debe trabajar sobre **su propio archivo**, para que la práctica sea segura y fácil de revisar.

:::note[Importante]
En esta práctica no vas a crear un repositorio desde cero. La idea es experimentar exactamente el flujo que viviría un estudiante cuando recibe una tarea publicada por el profesor.
:::

### Pasos

1. Haz **Fork** del repositorio.
2. Clona tu fork en tu computador.
3. Entra a `practica/participantes/`.
4. Usa `plantilla-perfil.md` como base.
5. Crea un archivo nuevo con tu nombre, por ejemplo:

```text
practica/participantes/ana-macias.md
```

6. Completa la información pedida.
7. Haz commit y push.
8. Abre tu Pull Request.

## Parte opcional: muro del taller

Si el grupo quiere una pequeña actividad colaborativa, cada docente puede añadir una línea en:

```text
practica/muro-del-taller.md
```

La idea es escribir:

- nombre;
- materia;
- una expectativa del taller.

## Por qué esta práctica funciona bien

- cada persona tiene una tarea clara;
- casi no genera conflictos al inicio;
- permite revisar rápido a muchos docentes;
- y además deja una evidencia real del flujo completo.

## Cómo sé que la práctica salió bien

- [ ] Tengo mi fork.
- [ ] Cloné el repositorio.
- [ ] Creé mi archivo personal en `practica/participantes/`.
- [ ] Hice commit y push.
- [ ] Abrí un Pull Request.

:::tip[Recomendación]
Haz primero la parte obligatoria del archivo personal. El muro compartido es un plus, no el núcleo de la práctica.
:::

## Qué viene después

Después de esta práctica, ya puedes entender mejor el flujo completo desde la perspectiva del estudiante y luego desde la del profesor.
