# Etapa 1: Git sin miedo

Si nunca has usado Git, empieza por aquí. No necesitas memorizar comandos ni entender todo hoy. Primero vamos a quitarle el miedo.

## ¿Qué es Git en palabras simples?

Git es una herramienta que guarda la historia de tus archivos. En lugar de terminar con nombres como `tarea-final-ahora-si.zip`, Git te permite registrar cambios paso a paso y volver atrás si algo sale mal.

Piensa en Git como una **máquina del tiempo** para tus proyectos.

## ¿Por qué debería importarle a un docente?

Porque en clase suele pasar esto:

- varios estudiantes entregan versiones distintas;
- los archivos se mezclan;
- es difícil saber quién cambió qué;
- corregir y dar seguimiento se vuelve cansado.

Git ayuda a resolver eso dejando un historial claro del trabajo.

## Qué problema resuelve

Con Git puedes:

- ver cambios con más orden;
- guardar avances importantes;
- recuperar versiones anteriores;
- construir una forma de trabajo más profesional para tus estudiantes.

## Palabras que vas a empezar a escuchar

### Repositorio

Es la carpeta o proyecto donde Git guarda tus archivos y también el historial de cambios.

### Commit

Es una “foto con intención” de un avance. No es solo guardar: es dejar registro de qué cambió y por qué.

### Historial

Es la lista de commits que muestra cómo fue creciendo o cambiando el proyecto.

## Qué NO necesitas dominar todavía

:::note[Respira tranquilo]
En esta etapa no necesitas saber ramas, rebase, conflictos complejos ni comandos raros. Solo vamos a entender la idea general.
:::
