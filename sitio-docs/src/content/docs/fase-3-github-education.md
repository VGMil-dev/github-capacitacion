# Apoyo: GitHub Education y Classroom

Cuando ya te sientas cómodo con el flujo manual, puedes explorar herramientas que automatizan parte del trabajo docente.

## GitHub Classroom

Es una herramienta gratuita que te permite:

- crear una clase digital;
- distribuir tareas automáticamente;
- integrar **autograding** en ciertos escenarios.

## Teacher Toolbox y beneficios docentes

Para usar Classroom al 100% y acceder a beneficios como **GitHub Copilot**, necesitas validarte como docente.

### Requisitos de validación

1. Entra a [education.github.com/teachers](https://education.github.com/teachers).
2. Usa tu correo institucional si está disponible.
3. Presenta documentación de respaldo:
   - credencial docente;
   - o carta oficial de la institución.

- cuando el flujo base ya te parezca sencillo;

- cuando la institución quiera escalar el uso de GitHub en clase.
