# Más adelante: Proyectos y auditoría

Cuando el equipo docente ya domina el flujo base, Git y GitHub también pueden ayudarte en escenarios más complejos.

## 1. Proyectos integradores

Si varias materias participan en un mismo proyecto, puedes organizar el trabajo dentro de un único repositorio con carpetas por área.

```text
proyecto-integrador-grupo1/
├── web/
├── movil/
├── electronica/
├── poo/
└── README.md
```

### Qué ventaja tiene

- cada profesor revisa una parte concreta;
- el trabajo queda más ordenado;
- se puede ver mejor el aporte individual y grupal.

## 2. Auditoría del trabajo real

Git deja huella del esfuerzo:

- quién trabajó;
- cuándo trabajó;
- cuánto aportó;
- si el avance fue progresivo o apareció todo de golpe al final.

## 3. Similitud y plagio

Cuando notes repositorios sospechosamente parecidos, GitHub y otras herramientas pueden ayudarte a comparar trabajo y detectar patrones repetidos.

## Cuándo volver a esta página

- cuando ya uses PRs con naturalidad;
- cuando varias materias revisen el mismo proyecto;
- cuando necesites más trazabilidad o más control sobre las aportaciones.
