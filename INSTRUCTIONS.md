# Instrucciones del Taller

Repositorio de práctica para una capacitación de **Git y GitHub para docentes**.

## Qué debes usar si participas en el taller

Si estás haciendo la práctica como participante, enfócate en esta carpeta:

`	ext
practica/
`

Ahí encontrarás:

- practica/README.md: instrucciones de la práctica;
- practica/participantes/plantilla-perfil.md: plantilla para tu archivo personal;
- practica/muro-del-taller.md: actividad opcional compartida.

## Cómo funciona el ejercicio

En este taller, este mismo repositorio actúa como el repositorio del profesor.

Tu rol será el de estudiante:

1. haces **Fork** de github-capacitacion;
2. clonas tu fork;
3. trabajas en practica/;
4. haces commit y push;
5. abres un Pull Request hacia este repositorio.

## Qué no necesitas tocar

La carpeta:

`	ext
sitio-docs/
`

contiene el sitio Astro/Starlight de la documentación del curso. **No necesitas modificarla** para completar la práctica.

## Si eres quien mantiene el curso

La documentación del sitio vive en sitio-docs/. Ahí están el proyecto Astro, el contenido del roadmap y la configuración del sitio.
